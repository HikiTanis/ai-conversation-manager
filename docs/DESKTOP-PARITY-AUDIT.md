## 模块核对

| 模块 | 结论 |
|---|---|
| Codex 本地目录、SQLite 索引、归档、压缩记录元数据、子代理关系 | 复用原扫描和分组模块；压缩消息预览仍受原读取器能力限制，不宣称支持所有压缩内容 |
| DSH workspace / sessions / archive / parent 关系 | 复用原 Node 适配器；来源切换隔离请求与状态 |
| Codex 正式包、旧 `.codexpack`、原始 `.codexbundle` | 打包／检查／导入路径存在；新摘要在导入前显示格式与内容 |
| DSH `.dshchat` / `.dshproject` | 原打包器与导入协议；摘要使用原清单验证器 |
| 多项目路径映射、冲突策略、覆盖备份 | 复用原项目还原器；文件与会话不是一个整体原子事务，部分文件已还原时错误会列出位置 |
| 同源合并、独立复制、父子 ID 重写、标题索引、可见性验证 | 复用原导入规划与索引器，合成数据覆盖重复合并与独立复制 |
| 会话删除／恢复／官方侧栏删除／缓存失效 | 复用原存储层；本轮补齐前端缺失的约束和修复规划 |
| 关闭保护、并发互斥、范围二次校验 | Tauri 写操作关闭保护＋引擎跨进程互斥＋执行前再次校验 |
| 中英界面 | 控件标签和本轮新增提示双语；底层历史异常／DSH 报告仍有部分中文，完整错误本地化待补 |
| 打包发布 | 仍为本地迁移预览；没有替换稳定版、创建新 Release 或把 C#/Node 存储引擎宣称为纯 Rust |

## 共用组件约束

- 所有按钮、输入、复选框、下拉、卡片、弹窗由 `desktop/src/components/ui.tsx` 提供；圆角／颜色／阴影来自 `tokens.css`。
- 四处下拉（导入对话策略、项目文件冲突、删除项目方式、回收站项目方式）使用同一组件，包括弹出列表、选中态、禁用态、方向键、Home/End、Enter、Escape、Tab 和文字查找。
- 下拉采用浏览器 top layer，避免被圆角卡片或对话框滚动区裁剪；根据可用空间向上或向下弹出。
- 同类复选框统一外观；按钮保留普通／主要／危险／文本四种语义变体。标签页、筛选胶囊是不同语义，不强行与普通按钮同形。
- 原生文件／目录选择器和 Windows 标题栏继续使用系统界面。

## 仍需迁移的优先顺序

1. P2：真实四阶段进度和持续操作日志，改善大备份／大导入等待体验。
2. P2：完整用户消息导航轨道、拖动、滚动定位，以及跨未加载分页的直接跳转。
3. P2：默认备份文件夹与自动连续命名、底层异常和 DSH 报告的完整本地化。

以上是仍有实际差异的项目，不将当前版本描述为旧版的完整等价迁移。
