# v2.0.1 数据安全审查

日期：2026-10-23。范围：新版桌面桥接、Codex 导入导出与删除恢复、DSH 存储与包流程。所有写入测试使用隔离夹具；没有对用户实际会话执行删除或导入测试。

## 已修复的问题

| 风险 | 修复后的行为 | 回归证据 |
| --- | --- | --- |
| 将缺失路径视为可永久删除会话，官方删除可能连带历史和子代理 | 侧栏检查只读；不调用官方删除，不移除索引、缓存或快照；旧修复记录不再触发后续删除 | 引擎故障测试、桌面诊断集成测试、前端无删除确认测试 |
| 索引仍指向 JSONL，但正文已压缩为 Zstandard | 检查原始和压缩两个路径；压缩副本存在时不判定为缺失 | 引擎与桥接压缩路径回归 |
| 官方删除已执行但响应丢失，异常清理删除了唯一暂存副本 | 任何删除异常都保留已暂存文件与元数据并报告位置 | 模拟实际移除文件后超时，逐字检查保留副本 |
| 清空旧回收站时误伤重新导入的同 ID 会话 | 仅删除明确选中的备份和侧车文件，不删除当前索引、缓存或恢复快照 | 引擎与 DSH 同 ID 重建测试 |
| 恢复仅检查原路径，忽略压缩副本或异路径同 ID | 恢复前严格扫描身份、索引与两种编码；冲突时保留备份并拒绝写入 | 索引冲突、未索引异路径冲突、压缩冲突和正常恢复 |
| 删除范围遗漏子代理，实际级联超出确认范围 | 合并文件元数据与索引父子关系，删除前核对完整递归范围；不完整或不可读即拒绝 | 压缩子代理遗漏测试；DSH 递归范围测试 |
| 导入失败回滚误删竞争写入文件，或覆盖后续修改 | 成功安装后才登记变更；哈希检查回滚对象；快照清理限于登记的导入文件 | 目标路径被其他写入者占用、替换前并发修改自动恢复、导入后追加内容、提交清理失败回归 |
| 旧恢复快照被去重删除 | 所有旧快照均保留到回收站；一般删除不附带销毁快照 | 多个不同内容快照保留测试 |
| 项目文件备份后发生修改，仍覆盖该文件 | 校验备份 ZIP 中实际字节哈希；原子替换捕获实际旧内容，发生竞争时保留 `.codex-preserved` 文件并报错停止 | 在替换瞬间注入修改，确认最新字节被保留 |
| DSH 合并丢弃目标端独有附件 | 先保留目标独有附件；同名不同内容拒绝合并；暂存和提交前校验完整目录 | 独有附件、冲突附件、合并故障回滚测试 |
| DSH 仅用长度和时间判断计划是否过期 | 使用文件内容指纹，第二次离线检查后再次校验；导出复查附件集合和同源索引 | 同长度同时间修改、预览后新增附件测试 |

## 验证边界与使用要求

这些结果证明上述已发现缺陷和测试场景受到保护，不能证明任意断电、磁盘损坏或第三方并发写入下绝不丢数据。导入、删除、恢复前仍应退出对应客户端并保留独立备份。

Codex 官方删除使用隔离模拟验证失败、超时与范围保护；没有为测试而删除真实用户会话。DSH 使用合成 workspace v2/session v4 数据，离线进程检查在测试子进程中模拟；真实 DSH 客户端重启与续聊尚未完成端到端验证。

项目文件还原仍是逐文件操作，整个目录不具备全局原子回滚。失败信息给出覆盖备份位置；竞争产生的最新内容保存在目标文件旁的 `.codex-preserved` 文件，需按报错路径手动恢复。新版本不会自动恢复旧版已删除的数据。

本地构建阶段 NuGet 漏洞源曾因网络受限不可达（NU1900），编译成功；此审查不构成依赖漏洞扫描结论。发布包不会自动替换用户正在运行的旧版程序；请完整安装或解压新包。
