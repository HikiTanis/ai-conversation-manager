# AI Conversation Manager v2.0.2

修复 v2.0.1 的回归：删除范围检查扫描本地文件时误调用导入校验，导致任何非零起始 ordinal 的分页片段都可能阻止删除，并显示“已取消导入”。

范围与恢复身份检查现在只读取并验证 session_meta、ID 和父子关系。保留重复 ID、路径、子代理范围及备份保护；导入和重建索引继续执行完整历史校验，不修改原文件的 ordinal。

新增隔离回归覆盖 ordinal 1604 的普通及压缩片段、无关文件不阻塞删除、选中片段先完整备份，以及独立导入仍拒绝不完整历史。中英文引擎自检通过。

关闭旧版管理器后，完整解压便携包到新目录再运行 Start.cmd。此修复不会自动删除任何会话，也不会改变旧的安全备份。
