# AI Conversation Manager v2.0.0

**正式版 · 2026-10-16 · Windows x64**

Codex Conversation Manager 正式更名为 **AI Conversation Manager（AI 对话管理器）**，面向 Codex 与 DeepSeek Harness（DSH）的对话及项目管理。仓库地址保持不变，2.0.0 为正式发行版本。

## 桌面架构全面升级

旧版 WPF 主界面升级为 React + TypeScript 界面与 Tauri + Rust 桌面宿主。界面组件、设计变量、数据源状态和操作流程统一维护；Rust 负责窗口、原生选择器、类型化命令白名单、进程调用与操作期间的关闭保护。

存储层通过独立读取／操作桥接继续使用 C# 与 Node 引擎，保留既有备份格式、父子关系、导入事务、删除协议、路径校验及恢复记录。这次是桌面架构全面升级，并非所有存储代码改写成 Rust；目前仍为 Windows x64 应用。

## 界面与工作流

- 统一 Codex／DSH 切换，项目侧栏、主对话／子代理和归档筛选。
- 跨项目保留所选对话，支持仅对话及完整项目备份。
- 重做备份、导入、回收站与设置维护入口，统一中英文布局和控件。
- 导入前展示包摘要，支持目标映射、智能合并、独立副本与项目文件冲突策略。
- 删除前展示实际范围及关联后代；数据变化后拒绝旧范围，项目永久删除需目录名确认。
- 多实例写操作互斥，操作期间阻止直接关闭窗口。

## 阅读与性能

- 正文恢复连续下滑，滚动时自动读取附近页面，不再手动点击“加载更多”。
- 使用动态高度虚拟列表，减少长会话同时挂载的消息数量。
- 数字导航覆盖完整会话，可直接跳转尚未加载的位置。
- 悬停或键盘聚焦数字可查看提问与回答摘录。
- 新增跨进程磁盘缓存，保存解析消息、导航与随机读取偏移，避免反复扫描和解压。
- 使用源路径、大小和时间信息判断缓存有效性；源文件更新或删除后失效。快照 24 小时过期，按约 512 MiB 预算清理；当前单个快照可能超过该预算。

## Codex 压缩历史兼容

- 支持 `.jsonl.zst` 与多帧 Zstandard 会话读取、预览、备份及导入。
- 备份保存完整解压 JSONL 和校验值，不受预览截断影响。
- 支持压缩包内容校验、父子／来源 ID 重写和目标会话合并。
- 新导入写入 JSONL；已有压缩目标合并后继续保持压缩，失败回滚保留原始压缩字节。
- 包含截断流、无效压缩流、归档父子会话、长文本及中文／emoji 回归测试。
- 缩短导入时的相邻临时文件名，避免较长 Windows 目录中因额外文件名后缀导致导入失败；长目录下的归档、压缩导入和重复合并纳入回归。

## 安装与升级

下载 `AI-Conversation-Manager-2.0.0-Windows-x64-Setup.exe` 或 `AI-Conversation-Manager-2.0.0-Windows-x64-Portable.zip`，使用 `SHA256SUMS.txt` 验证。安装包支持中英文、当前用户安装及缺失 WebView2 自动下载；免安装版完整解压后运行 Start.cmd。Node.js 和相关许可证随包附带。

需要 Windows 10/11 x64、.NET Framework 4.8 和 WebView2。从 1.x 升级请使用新目录；旧数据与旧备份无需转换，旧 WPF 程序不会自动卸载。二进制尚未签名。

## 验证与已知边界

前端交互、Rust 命令校验、C# 中英文自检、Codex／DSH 备份导入与回滚、Zstandard、缓存复用与失效使用自动化验证；长会话导航与悬停界面另外进行浏览器检查。GitHub 工作流执行正式构建、测试、打包及产物验证。

- Codex CLI 0.148.0 or later / Codex CLI 0.148.0 或更高版本用于删除与侧栏修复。
- DSH 基线为 Desktop 0.2.0-rc.2；真实会话写入后重启与继续对话尚未完成端到端验证。
- DSH 日志 128 MiB、预览 200 万字符；桌面单条预览 100,000 字符，截断会标记。
- Codex rollout 解压 8 GiB，ID 重写单项 512 MiB。
- 项目文件恢复与会话导入不是整体原子事务，已恢复项目文件不随会话失败全部回滚。
- 仍使用既有存储引擎，未提供跨平台构建；实时分阶段进度与持续日志仍是后续改进项。
- Codex 与 DSH 不互相转换格式。操作前退出对应客户端，保留备份至目标会话验证完成。
