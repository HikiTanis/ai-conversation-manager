# AI Conversation Manager v2.1.0

新增启动自动检查与软件内更新：发现新版本时展示更新说明，点击“立即更新并重启”后下载、校验并完成升级。支持手动检查、关闭启动检查、下载进度与失败重试。

安装版保持原安装目录；便携版在当前目录更新，保留旧程序文件备份并在替换失败时回滚。更新与会话写入操作互斥，只更新程序文件，不修改对话或项目数据。

2.0.3 及更早版本需先手动升级一次，之后可使用软件内更新。请完整安装或解压，保留 `engine/` 目录。

下载文件为 `AI-Conversation-Manager-2.1.0-Windows-x64-Setup.exe`、`AI-Conversation-Manager-2.1.0-Windows-x64-Portable.zip` 和 `SHA256SUMS.txt`。

行为与限制见 [更新功能说明](https://github.com/HikiTanis/ai-conversation-manager/blob/v2.1.0/docs/UPDATES.md)。
