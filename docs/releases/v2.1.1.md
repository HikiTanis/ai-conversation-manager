# AI Conversation Manager v2.1.1

修复新版 Codex 桌面端删除会话后，任务侧栏仍保留条目的问题。新版桌面端使用 `sqlite/codex.db`，此前工具只处理 `codex-dev.db`；现在优先处理正式版目录，旧环境继续兼容原目录。

删除前仍保留备份与运行状态检查，仅处理所选会话范围。回归验证覆盖新旧目录并存、删除指定条目、保留其他条目和回收站副本。

v2.1.0 用户可点击软件右上角“检查更新”升级。2.0.3 及更早版本需手动安装或完整解压新版。执行删除前请完全退出 Codex，完成后重新打开。

本次修复适用于后续删除操作。已经产生的历史残留需要按具体会话核对，不会仅凭会话文件缺失自动批量清理；请勿为了清除残留再次删除其他会话。

附件包括 Windows x64 安装版、便携版、`SHA256SUMS.txt` 和供软件自动更新使用的 `update.json`。
