# AI Conversation Manager v2.0.3

修复 Codex 删除时将同一会话的分页文件误判为重复 ID，以及旧版侧栏修复留下的单行占位文件与同名压缩原件冲突、阻止删除的问题。

- 删除范围核对包含每条会话的全部分页文件，并显示涉及的文件数；确认前核对所有文件的指纹。
- 每条会话的多个文件作为一个回收站条目保存，恢复前检查整组备份、哈希和目标冲突，清空仅处理该组备份。
- 对明确标记为旧侧栏修复、仅含一行元数据的占位文件，保留它与压缩原件的备份；恢复时以原件作为索引入口。含额外记录或无法确认的重复副本仍拒绝删除。
- 会话列表优先采用 Codex 当前索引指向的分页文件。

本地中英文引擎自检、17 项界面测试、16 项桥接集成测试通过。新增回归覆盖多分页备份恢复、文件变化、旧修复占位文件与压缩原件的完整恢复；本地测试版已由用户确认可用。

## 下载与验证

- `AI-Conversation-Manager-2.0.3-Windows-x64-Setup.exe`：Windows x64 安装包。
- `AI-Conversation-Manager-2.0.3-Windows-x64-Portable.zip`：关闭旧版管理器，完整解压到新目录后运行 `Start.cmd`。
- `SHA256SUMS.txt`：两个发行文件的 SHA-256。

升级不会自动删除会话。真实 DSH 客户端重启、续聊仍未完成端到端验证；其他数据安全边界见 [审查记录](https://github.com/HikiTanis/ai-conversation-manager/blob/v2.0.3/docs/DATA-SAFETY-AUDIT.md)。
