# AI Conversation Manager v2.0.1

这是数据安全修复版本，建议 2.0.0 及更早版本用户升级。升级不会自动恢复已被旧版本删除的内容。

## 关键修复

- **侧栏检查改为只读诊断**：不再因路径缺失调用永久删除，保留索引、缓存与恢复材料；正确识别 `.jsonl.zst`，停用旧修复记录的后续清理。
- **删除失败保留备份**：即使官方删除已执行但响应超时，暂存副本仍然保留并报告位置。
- **回收站相互隔离**：清空旧条目不会删除重新导入的同 ID 对话及其索引；恢复前检查压缩副本、全目录身份冲突。
- **删除范围复核**：核对递归子代理范围，不完整或不可读时拒绝执行。
- **导入与回滚加固**：按内容哈希检查变更，仅回滚本次拥有的文件，保留后续修改；原子替换前的并发编辑会被恢复。
- **项目文件覆盖保护**：校验实际备份字节；替换瞬间出现的新内容保留为 `.codex-preserved` 文件，报告路径并停止后续操作。
- **DSH 附件保护**：合并保留目标独有附件，同名不同内容拒绝覆盖；计划与写入前校验内容指纹；导出复查附件集合和同源索引。

## 下载与升级

- `AI-Conversation-Manager-2.0.1-Windows-x64-Setup.exe`：Windows x64 安装包。
- `AI-Conversation-Manager-2.0.1-Windows-x64-Portable.zip`：完整解压到新目录后运行 `Start.cmd`。
- `SHA256SUMS.txt`：核对两个发行文件的 SHA-256。

关闭旧版管理器后使用整套新包，保留 `engine/` 目录，避免混用旧引擎。数据格式不变，无需迁移现有备份。运行要求仍为 Windows 10/11 x64、.NET Framework 4.8 和 WebView2；包内附带 Node.js。程序尚未进行 Authenticode 签名。

## 验证与边界

本地完整引擎自检通过；桌面桥接 15 项、DSH 后端 23 项、前端 17 项、Rust 2 项测试通过，包含删除响应丢失、竞争写入、失败回滚和只读诊断回归。所有写入测试均使用隔离夹具。

真实 DSH 客户端重启与续聊尚未完成端到端验证。项目文件还原是逐文件操作，失败时可能需要根据报错手工恢复备份。导入、删除与恢复前请退出对应客户端，并保留独立备份。上述测试不保证任意断电、磁盘损坏或第三方并发操作下绝不丢失数据。
